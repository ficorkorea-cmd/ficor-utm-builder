# FICOR UTM 빌더

GA4 유입 데이터의 표기를 통일하기 위한 사내 UTM 링크 생성 도구입니다.
매체마다 링크 표기가 달라 GA4 리포트가 흩어지는 것을 막기 위해, 링크를 만드는 모든 담당자가 같은 규칙으로 링크를 생성합니다.

## 기능

| 탭 | 기능 |
|---|---|
| URL 생성 | 랜딩 URL → 매체 선택 → (필요 시) 프로모션·상품·소재명 → URL 복사 / 단축 URL / QR |
| URL 검사 | 기존 링크를 붙여넣으면 규칙에 맞지 않는 부분만 표시 |
| 생성 기록 | 복사한 링크 자동 저장(각자 브라우저), 검색, CSV 내보내기 |
| 작성 가이드 | 사용 방법, 표기 규칙, 매체별 값, 코드표, 예시 |

자동 처리
- 캠페인 = `프로모션_상품_시작일` (기본값: 상시 · 전 상품 · 오늘)
- 인스타·스레드 프로필/스토리 링크는 소재명(`profile`, `story`) 자동 입력
- 스마트스토어 링크 → `nt_` 파라미터로 변환 / 쿠팡 링크 → 생성 안 함
- 메타 광고 → 광고관리자 'URL 매개변수' 칸용 매크로 생성 가능

## GitHub에 올리기 (최초 1회)

1. GitHub에서 **New repository** → 이름 예: `ficor-utm-builder`
   - 공개(Public)로 만들어야 무료 플랜에서 Pages를 쓸 수 있습니다. (비공개 저장소의 Pages는 유료 플랜 필요)
   - 페이지에는 검색엔진 노출 차단(`noindex`)이 적용되어 있습니다.
2. 저장소 화면에서 **Add file → Upload files** → 이 폴더의 파일을 전부 끌어다 놓고 **Commit changes**
3. **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → **Save**
4. 1~2분 후 같은 화면 상단에 표시되는 주소(`https://<계정>.github.io/ficor-utm-builder/`)를 유관부서에 공유

## 규칙(사전) 수정 방법

모든 선택지와 가이드 내용은 `presets.js` 한 파일에서 나옵니다.
값을 추가하면 생성 탭의 드롭다운, 검사 로직, 작성 가이드 탭에 자동 반영됩니다.

| 하고 싶은 것 | 수정 위치 |
|---|---|
| 상품 추가 (예: 발목) | `products`에 `{ code: "ankle", label: "발목" }` 추가 |
| 프로모션 추가 | `promotions` |
| 매체 추가 | `channels` (source · medium · 소재명 필수 여부) |
| 자사몰 도메인 추가 | `domains.mall` |

수정 규칙
- `code`는 영문 소문자 · 숫자 · 밑줄(_)만 사용
- 이미 쓰던 값은 지우지 말고 `deprecated: true`를 붙여 목록에서만 숨김 (과거 GA4 데이터 해석용)
- 수정 후 `changelog`에 날짜와 내용 한 줄 추가 → 가이드 탭 '변경 이력'에 표시

GitHub에서 수정: 파일 열기 → 연필 아이콘 → 수정 → **Commit changes** → 1~2분 후 반영

## GA4 권장 설정

카카오 · 문자 · 인플루언서는 GA4 기본 채널 그룹에 없는 매체라 'Unassigned'로 분류됩니다.
GA4 **관리 → 데이터 표시 → 채널 그룹**에서 사용자 정의 채널 그룹을 만들어 아래 조건을 추가하면 리포트에서 별도 줄로 보입니다.

| 채널 이름 | 조건 |
|---|---|
| Message | 세션 매체 = `message` |
| Influencer | 세션 매체 = `influencer` |

## 파일 구조

| 파일 | 역할 | 수정 |
|---|---|---|
| `index.html` | 화면 | ✕ |
| `presets.js` | 규칙 사전 (매체·목적·상품·프로모션·예시·변경 이력) | **이 파일만 수정** |
| `app.js` | 생성 · 검사 · 기록 · 단축 URL · QR 로직 | ✕ |
| `rules.js` | 규칙 검사 | ✕ |
| `guide.js` | 작성 가이드 · 도움말 렌더링 | ✕ |
| `style.css` | 디자인 | ✕ |
| `.nojekyll` | GitHub Pages가 파일을 변환하지 않도록 하는 빈 설정 파일 | ✕ |

서버 없이 동작하며, 입력값과 생성 기록은 외부로 전송되지 않고 각자 브라우저에만 저장됩니다. (글꼴·QR 라이브러리는 jsDelivr CDN에서 불러오며, '단축 URL 만들기'를 누를 때만 완성 URL이 is.gd로 전송됩니다.)
